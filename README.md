# OLD 目录说明

这个目录用于封存历史阶段的项目记录与实验材料（如早期日志、流程稿、阶段总结等）。

## 作用
- 保留历史上下文，避免直接删除导致信息丢失。
- 将“不可复现 / 口径不一致 / 已过时”的材料与当前有效记录隔离。
- 让当前工作目录只保留可复现、可追踪的最新结果。

## 使用约定
- 旧材料一旦迁入 `OLD/`，默认不作为当前实验结论依据。
  OLD/拒绝自动写入
- 当前实验结论统一以以下位置为准：
  - `experiment/*/log/*summary*.json`
  - `project_records/experiment_res.md`
- 若后续需要回溯历史，请在引用时明确标注“来自 OLD 封存资料”。
